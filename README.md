# The-Battle-to-Defend-the-Nose
这个想法其实挺适合做荒诞小游戏，但名字需要注意。
如果公开上线，我不建议真的叫：
根治你的鼻炎

因为“根治”很容易让人理解成医疗效果承诺。
可以把它彻底游戏化，比如：
《鼻子保卫战》

或者：
《今天鼻子通了吗？》

玩法可以非常简单。
屏幕中央一个鼻子：
        🌸 花粉
          ↓

 🦠 →    👃    ← 🐈猫毛

          ↑
        ❄️冷空气

玩家需要阻止：
- 花粉
- 灰尘
- 猫毛
- 冷空气
- 烟雾
进入鼻孔。
进入一个：
🤧 +1

连续进入：
喷嚏 × 3

然后屏幕震动。
游戏循环
非常适合手机：
30 秒一局

↓

污染源不断飞向鼻子

↓

点击 / 滑动清除

↓

速度越来越快

↓

最终：

你的鼻子坚持了 47 秒
击败了 83% 的鼻炎人

这里“击败百分之多少”第一版也可以用模拟值，不一定需要服务器。
